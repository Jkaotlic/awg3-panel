# Подбор мусорных пакетов на Keenetic

В полной сборке панель может проверить несколько вариантов `Jc`, `Jmin` и
`Jmax` через отдельный тестовый туннель в AWG Manager. Панель сравнивает
текущие значения туннеля и три сгенерированных варианта. На каждый вариант
приходятся три запуска туннеля. Успешный запуск подтверждают новое
рукопожатие, передача данных в обе стороны и HTTP-проверки через тестовый
интерфейс. Панель рекомендует вариант с наибольшим числом успешных запусков,
затем учитывает медиану задержки.

## Привязка

1. Выделите в панели отдельный включённый тестовый пир. Скачайте его обычный
   `.conf` и импортируйте в AWG Manager. Используйте совместимый с AWG 3.1
   туннель с бэкендом `kernel`.
2. Остановите тестовый туннель. Отключите его использование маршрутом по
   умолчанию, привязки к клиентам, DNS и политикам доступа, внешние
   обфускаторы и мониторинг с авторестартом. Сохраните клиентский
   `AllowedIPs = 0.0.0.0/0` и штатную HTTP-проверку доступности.
   Уберите также привязки из внешних скриптов и политик. На время замеров
   воздержитесь от ручных изменений этого туннеля в AWG Manager.
3. Дайте сервису панели доступ к AWG Manager по доверенной сети управления.
   Используйте HTTPS или локальный HTTP-адрес. Разместите REST-ключ и
   отдельный MCP-ключ AWG Manager в двух файлах, доступных только владельцу
   сервиса. MCP-ключ должен разрешать изменение параметров AWG и
   включение/выключение тестового туннеля.
4. Передайте настройки в окружение сервиса `awg3panel`, например через
   `EnvironmentFile` в systemd drop-in. После добавления настроек перезапустите
   панель. При изменении конфигурации сначала дождитесь завершения подбора.

| Переменная | Значение |
| --- | --- |
| `AWG3PANEL_TUNE_URL` | Адрес AWG Manager, например `https://router.example.com` |
| `AWG3PANEL_TUNE_IFACE` | ID серверного интерфейса в панели |
| `AWG3PANEL_TUNE_PEER` | ID тестового пира из ссылки на его клиентский конфиг |
| `AWG3PANEL_TUNE_REST_TOKEN_FILE` | Путь к файлу с REST-ключом для чтения состояния |
| `AWG3PANEL_TUNE_MCP_TOKEN_FILE` | Путь к файлу с отдельным MCP-ключом |
| `AWG3PANEL_TUNE_TUNNEL` | ID тестового туннеля в AWG Manager |
| `AWG3PANEL_TUNE_TUNNEL_NAME` | Точное имя того же туннеля |
| `AWG3PANEL_TUNE_ENDPOINT` | Точный `Endpoint` импортированного пира, например `203.0.113.20:3478` |
| `AWG3PANEL_TUNE_ROUTE` | Ожидаемый маршрут AWG Manager. Если переменная пуста, допускается автоматический или заданный в туннеле прямой WAN. Для точной привязки укажите `auto`, `wan:<интерфейс>` или `tunnel:<id>` |

## Запуск

Откройте QR и конфиг тестового пира, затем нажмите **Подобрать на Keenetic**.
В окне появляются попытки, число успешных запусков и медиана задержки.
После завершения, отмены или тайм-аута панель возвращает исходные
`Jc/Jmin/Jmax` и оставляет тестовый туннель выключенным. Если связь потерялась
или процесс остановился, панель читает журнал и пробует восстановить
исходное состояние при следующем запуске подбора. При постороннем изменении
туннеля автоподбор останавливается до ручной проверки.

Выберите успешный вариант и нажмите **Использовать выбранный**. Панель
сохранит тройку в клиентском профиле этого пира. Возьмите обновлённый
`.conf` или QR, чтобы перенести значения на клиент.

То же окно показывает фактическую мимикрию пира и даёт скачать
контрольный `.conf` без `I1–I5`. Такой файл позволяет сравнить связь с
теми же остальными параметрами. При генерации параметров нового интерфейса
доступен выбор профиля, включая экспериментальный SIP.
