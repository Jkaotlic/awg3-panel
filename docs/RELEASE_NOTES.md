Учебный стенд настройки и проверки сетевых подключений.

- Готовый комплект для чистых Ubuntu 24.04 / Debian 13, Linux amd64, systemd/TUN.
- Простой установщик с проверкой SHA256 и сохранением исходного комплекта для повторного запуска.
- Панель управления, первый клиентский профиль и приватный файл доступа.
- Автоматические персональные параметры новых подключений.
- Проверки сборки, бинарников и реального userspace-туннеля на двух системах.

Начните с [инструкции](https://github.com/Jkaotlic/awg3-panel/blob/main/docs/install.md).
Не публикуйте сгенерированные ключи, пароли или клиентские профили.
IPv4/DNS/IPv6 и доступность у конкретного провайдера проверяются отдельно.
