## AWG3 Panel v0.4.0

- Автоподбор через выделенный туннель Keenetic проверяет сочетания `Jc/Jmin/Jmax` и `I1–I5`. Можно выбрать профиль сигнатуры, пул доменов, лимит попыток и порог успеха.
- Панель рекомендует вариант по успешности замеров и задержке. Из результатов можно скачать конфиг попытки или сохранить её параметры в тестовый профиль.
- Генератор нового интерфейса готовит серверный и клиентский блоки. Доступны копирование маскировки из рабочего пира, ручной ввод размеров мусорных пакетов, джиттер таймеров, паддинг, `DisableCookies` и `RandomTrailers`.
- Для полного автоподбора через закрытый SSH-проброс обновите локальный мост из комплекта. [Подключение тестового туннеля](https://github.com/Jkaotlic/awg3-panel/blob/v0.4.0/docs/keenetic-junktune.md)

## Установка

На чистом VPS выполните:

```bash
curl -fsSLo install.sh https://github.com/Jkaotlic/awg3-panel/releases/download/v0.4.0/install.sh
sudo bash install.sh --version v0.4.0
```

На действующей установке сохраните согласованный снимок конфигурации и состояния перед заменой бинарника панели. [Подготовка VPS, первый вход и откат](https://github.com/Jkaotlic/awg3-panel/blob/v0.4.0/docs/install.md)
