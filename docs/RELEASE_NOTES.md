## AWG3 Panel v0.4.1

- Щелчок по имени пира открывает карточку с состоянием связи, QR, скачиванием конфига и настройками. После сохранения карточка сразу предлагает актуальный конфиг.
- Параметры автоподбора свёрнуты. Быстрый переход к проверке на Keenetic доступен в карточке тестового пира.
- Рекомендацию автоподбора можно подставить в редактор другого пира на том же интерфейсе. Панель сохраняет её после подтверждения в форме. [Работа с тестовым туннелем](https://github.com/Jkaotlic/awg3-panel/blob/v0.4.1/docs/keenetic-junktune.md)

## Установка

На чистом VPS выполните:

```bash
curl -fsSLo install.sh https://github.com/Jkaotlic/awg3-panel/releases/download/v0.4.1/install.sh
sudo bash install.sh --version v0.4.1
```

На действующей установке сохраните согласованный снимок конфигурации и состояния перед заменой бинарника панели. [Подготовка VPS, первый вход и откат](https://github.com/Jkaotlic/awg3-panel/blob/v0.4.1/docs/install.md)
