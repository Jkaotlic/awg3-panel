## AWG3 Panel v0.2.0

- Мастер установки для чистых Ubuntu 24.04 и Debian 13 amd64. Проверяет VPS и SHA256 комплекта, показывает предпросмотр и ждёт явного подтверждения. После установки показывает шаги первого подключения и входа.
- Ядро AmneziaWG Go обновлено до `v3.1.20261116`. Установка и откат берут общую блокировку, откат проверяет очистку правил firewall.
- Панель сохраняет все маршруты пира и серверные параметры при отключении. Журнал восстанавливает незавершённые изменения пиров, а сверка с устройством останавливает запись при расхождении.
- Запросы attach/detach применяются по ревизии конфига и подтверждённому предпросмотру. В консоли усилены авторизация, проверка запросов и привязка действий к выбранному интерфейсу.

## Установка

Выполните на чистом VPS по SSH:

```bash
curl -fsSLo install.sh https://github.com/Jkaotlic/awg3-panel/releases/download/v0.2.0/install.sh
sudo bash install.sh --version v0.2.0
```

[Подготовка VPS, первый вход и откат](https://github.com/Jkaotlic/awg3-panel/blob/v0.2.0/docs/install.md)

Для действующей установки сначала сохраните согласованный снимок конфигов и состояния. Новая панель читает `peers.json` версии 2 и при записи использует версию 3. Для возврата к бинарнику, который читает только версию 2, нужен снимок до обновления. Заявки attach/detach без ревизии нужно пересоздать.
