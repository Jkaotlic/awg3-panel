## AWG3 Panel v0.5.0

- Разделы панели получили постоянную навигацию, которая адаптируется к узкому экрану.
- В списке подключений появились поиск и фильтр по состоянию. Карточка, редактор и скачивание конфига доступны прямо из списка.
- Карточка подключения собирает статус, QR, конфиг и настройки. В редакторе обычные параметры и параметры AWG сгруппированы отдельно, а кнопка сохранения видна при прокрутке.
- На экране автоподбора видны тестовое подключение, параметры и результаты. Рекомендация открывает заполненный редактор выбранного подключения. [Работа с тестовым туннелем](https://github.com/Jkaotlic/awg3-panel/blob/v0.5.0/docs/keenetic-junktune.md)

## Установка

На чистом VPS выполните:

```bash
curl -fsSLo install.sh https://github.com/Jkaotlic/awg3-panel/releases/download/v0.5.0/install.sh
sudo bash install.sh --version v0.5.0
```

На действующей установке сохраните согласованный снимок конфигурации и состояния перед заменой бинарника панели. [Подготовка VPS, первый вход и откат](https://github.com/Jkaotlic/awg3-panel/blob/v0.5.0/docs/install.md)
