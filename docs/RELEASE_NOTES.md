## AWG3 Panel v0.3.0

- В окне QR и конфига можно сгенерировать и сохранить `Jc/Jmin/Jmax` отдельно от остальных настроек пира.
- Опциональный автоподбор через отдельный тестовый туннель AWG Manager на Keenetic проверяет четыре варианта по три запуска, показывает успешность и задержку и сохраняет выбранные значения после подтверждения. [Подключение тестового туннеля](https://github.com/Jkaotlic/awg3-panel/blob/v0.3.0/docs/keenetic-junktune.md)
- Панель показывает фактическую мимикрию пира и выдаёт контрольный конфиг без `I1–I5`. Генератор нового интерфейса поддерживает QUIC, DNS, STUN и экспериментальный SIP.
- Исправлены удаление из многострочных списков YAML, применение нескольких заявок интерфейсов, проверка клиентских умолчаний и обновление службы через прежний установщик.

## Установка

На чистом VPS выполните:

```bash
curl -fsSLo install.sh https://github.com/Jkaotlic/awg3-panel/releases/download/v0.3.0/install.sh
sudo bash install.sh --version v0.3.0
```

На действующей установке сохраните согласованный снимок конфигурации и состояния перед заменой бинарника панели. [Подготовка VPS, первый вход и откат](https://github.com/Jkaotlic/awg3-panel/blob/v0.3.0/docs/install.md)
