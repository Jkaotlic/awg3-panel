## AWG3 Panel v0.5.1

- Из карточки подключения можно скачать эталон A и тестовый вариант B для проверки на устройстве клиента. B отключает I1–I5, а при их отсутствии переключает мусорные пакеты. Оба файла относятся к одному клиенту и скачиваются без сохранения настроек.
- Автоподбор Keenetic показывает привязанный тестовый туннель, ведёт по шагам и переводит к результатам после старта. Замеры относятся к маршруту привязанного роутера. [Работа с тестовым туннелем](https://github.com/Jkaotlic/awg3-panel/blob/v0.5.1/docs/keenetic-junktune.md)
- «Настройки по умолчанию» поясняют, когда панель использует общие значения выбранного интерфейса при выдаче клиентских конфигов.

## Установка

На чистом VPS выполните:

```bash
curl -fsSLo install.sh https://github.com/Jkaotlic/awg3-panel/releases/download/v0.5.1/install.sh
sudo bash install.sh --version v0.5.1
```

На действующей установке сохраните согласованный снимок конфигурации и состояния перед заменой бинарника панели. [Подготовка VPS, первый вход и откат](https://github.com/Jkaotlic/awg3-panel/blob/v0.5.1/docs/install.md)
