    Параметры обфускации для нового интерфейса
    
  
  
    Ничего не применено. Это заготовка для нового туннеля:
    вставьте её в [Interface] нового сервера руками.
    Действующий интерфейс не затронут.
    
  
    
    Комплект выпускается целиком случайным (источник — crypto/rand на сервере)
    и удовлетворяет правилам протокола AmneziaWG 3.1: S1 = S2 = S3 = S4
    в коридоре 12..32 (равные S закрывают потерю транспортных пакетов при
    RandomTrailers), H1..H4 — непересекающиеся
    диапазоны вида x-y, попарно различны и не меньше 5.
    Каждое нажатие даёт новый комплект — панель не запоминает ни один из них.

    Мусорные пакеты клиента
    
      
    
    
    
    
    
    Для клиентского конфига или вкладки «Умолчания».

    
    
      
    Сигнатурный пакет I1 — тоже в defaults.json, не на сервер
    
    
    
    
    
    
    
      Клиентское поле — сервер его не знает и в блок [Interface] выше
      оно не входит. И это НЕ тот I1, который в итоге получит этот
      интерфейс: при первом создании defaults.json для НОВОГО интерфейса
      панель сеет туда свой, независимо сгенерированный I1 — это значение
      с ним не связано. Пригодится, только если вы заводите
      defaults.json руками до первого запуска интерфейса и хотите
      сразу готовое значение, а не через кнопку «Сгенерировать I1» на уже поднятом интерфейсе.
